## **Research & Project Work**

### **Helios Solar Radio Burst Detection — SUNRISE Project (Ongoing)**
Research effort supporting the analysis of SRB events in historical Helios spacecraft data. Contributions include:
- Development of early-stage signal processing routines for identifying radio burst signatures  
- Design of automated classification methods for SRB detection  
- Tooling for data preparation and visualization within the SUNRISE heliophysics pipeline  

---

### **Resonant — From-Scratch Game Boy Advance Engine & RPG (In Progress)**
A fully custom **Game Boy Advance game engine and RPG**, implemented entirely in ISO C and supported by bespoke Python tooling. Core components include:
- Low-level VRAM/OAM management, tile streaming, and background/sprite pipelines  
- A Pokémon-inspired battle system with state machines, animation sequencing, and modular UI layers  
- A complete overworld engine featuring NPC logic, map loading, collision systems, and player state management  
- A custom Python asset toolchain converting PNG graphics into raw GBA-native data formats  
- A large-scale architecture spanning ~500 source files across 30+ subsystems  

---

### **Board Game Simulation Engine (Final Stages)**
A complete systems-level implementation of the strategy game *Triumph and Tragedy* using **C++ and SDL2**. Project components include:
- Full replication of game logic and multi-phase mechanics  
- Custom event-driven UI  
- State synchronization and rule validation subsystems  

---

### **Approximate Distance Oracle — Thorup–Zwick (2005) Implementation (Completed)**
A computational recreation of the **Thorup–Zwick approximate distance oracle**, including:
- Hierarchical clustering procedures  
- Stretch analysis for query accuracy  
- Empirical evaluation of preprocessing and query performance  

---

### **Hamiltonian Cycle to TSP Reduction Visualizer (In Progress)**
A JavaScript-based interactive demonstration illustrating classical NP-hard reductions, focusing on:
- Graph embedding and transformation visualization  
- Stepwise reduction logic  
- Educational explanations of complexity-theoretic concepts
