## **Featured Research & Projects**

### **[Helios Solar Radio Burst Detection — SUNRISE Project](https://github.com/Kasper-Heliophysics-MDP/SolarBurstGAN)** (Ongoing)
**Problem:** Detect and classify Solar Radio Burst (SRB) events in historical Helios spacecraft data.  
**Approach:** Developed preprocessing pipelines, signal characterization routines, and automated classification algorithms for large SRB datasets.  
**Contributions:**  
- Implemented early-stage signal processing routines to identify candidate SRB signatures  
- Designed automated classification workflows for accurate detection  
- Built tooling for data visualization and integration into the SUNRISE pipeline  
**Results:** Enabled scalable, reproducible SRB detection across historical mission archives.

### **[Thorup–Zwick Approximate Distance Oracle (2005) Implementation](https://github.com/MichShep/ADO_Simulator)**
**Problem:** Efficiently compute approximate shortest-path distances in large-scale graphs with provable stretch guarantees.  
**Approach:** Implemented hierarchical clustering, landmark selection, and query algorithms based on Thorup–Zwick (2005) methodology.  
**Contributions:**  
- Developed preprocessing and query modules with configurable tradeoffs between space, latency, and accuracy  
- Empirically analyzed stretch and performance on large synthetic and real-world graphs  
**Results:** Demonstrated accurate distance queries while reducing memory footprint, suitable for teaching or research-level graph experiments.

### **[Resonant — Game Boy Advance Engine & RPG](https://github.com/MichShep/Resonant)**
**Problem:** Build a fully custom GBA game engine and RPG from the ground up in C, exploring low-level graphics and state management.  
**Approach:** Implemented VRAM/OAM pipelines, animation sequencing, tile streaming, battle systems, and overworld engine; developed Python tooling for asset conversion.  
**Contributions:**  
- Low-level graphics engine for background and sprite management  
- Modular battle and overworld systems  
- Custom Python asset toolchain for GBA-native formats  
**Results:** ~50 source files across 20+ subsystems; full RPG architecture suitable for expansion and educational exploration.

---

### **[Pix2GBA — GBA Asset Toolchain](https://github.com/MichShep/pix2gba)**
**Problem:** Efficiently convert 2D images into GBA-native graphics formats for custom engines and games.  
**Approach:** Built a Python toolchain to process PNG/sprite assets into raw VRAM/OAM-compatible data for GBA, supporting palettes, tile compression, and sprite sequencing.  
**Contributions:**  
- Automated pipelines for tile conversion, palette management, and sprite data generation  
- Integrated with custom GBA engines to streamline asset loading  
- Optimized processing for large sprite sheets and multiple resolutions  
**Results:** Simplified workflow for GBA development; used in the **Resonant** project for graphics assets.

---

### **[Insane Space Survival — Unity C# Game](https://github.com/MichShep/InsaneSpaceSurvival)**
**Problem:** Create a procedurally generated spaceship survival game where ship systems interact dynamically via events.  
**Approach:** Built a Unity C# engine using an **Event Bus** pattern to manage ship systems, events, and player interactions; procedural generation populates ships with varying modules and hazards.  
**Contributions:**  
- Developed a flexible event-driven architecture connecting ship systems, player actions, and environmental events  
- Implemented procedural ship generation with modular systems and hazards  
- Designed core gameplay mechanics including resource management, system failures, and survival objectives  
**Results:** Fully playable prototype demonstrating emergent gameplay and modular system interactions; architecture supports easy expansion.
